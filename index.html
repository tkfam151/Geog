Learn

Three ideas. That's all.

1

Along the corridor, then up the stairs.

Always read the numbers across the bottom first (eastings), then the numbers up the side (northings).

2

4-figure: name the square.

Use the bottom-left corner of the square. Easting 24 + northing 45 gives 2445.

3

6-figure: split into tenths.

Imagine each side cut into 10. Count how many tenths across, then up. 24·3 and 45·7 give 243457.

4

Know your compass.

North is always the top of the map. Remember the order clockwise: Never Eat Soggy Waffles. In-between points join the two names, like north-east.

💡

Remember: "You have to go along the corridor before you can go up the stairs." Eastings first, then northings. Every time.

    Cheat sheet

    Everything on one card.

    4-figure

    1. Find the square.
    2. Go to its bottom-left corner.
    3. Read the easting (along).
    4. Read the northing (up).
    5. Write them together: 2445

    6-figure

    1. Start with the 4-figure square.
    2. Split the square into 10 × 10.
    3. Count tenths across: add after the easting.
    4. Count tenths up: add after the northing.
    5. Write: 243 457

    Common mistakes

    • Reading northings first.
    • Using the top-right corner instead of bottom-left.
    • Counting tenths from the wrong side.
    • Forgetting a 4-figure ref is a square, but a 6-figure ref is a point (to 100 m).
