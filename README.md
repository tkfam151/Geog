# Grid References

**Live site:** https://tkfam151.github.io/Geog/

A one-page study site for KS3 geography: learn, explore and practise 4-figure and 6-figure grid references.

- **Learn**: eastings vs northings, 4-figure and 6-figure references and the 8-point compass, with diagrams.
- **Five maps**: Village, Coast, Town, Hills (contours and spot heights) and Tricky numbers (the grid crosses 99 → 00). Each has different grid numbers.
- **Explore**: click or tap anywhere to drop a pin and get its 4- and 6-figure reference, with the square zoomed into tenths. Tap symbols, or type a reference to find it.
- **Teaching tools**: Projector mode (full screen), Hide answers with a Reveal button, Class challenge (find this reference / what's here?), and a printable worksheet with an answer sheet for any map.
- **Practise**: 10-question quizzes on any map, in three modes (4-figure, 6-figure, Mixed with compass directions), with feedback, best scores, a review of missed questions and keyboard shortcuts (1–4, Enter).
- **Cheat sheet**: the steps and common mistakes on one card.

Plain HTML, CSS and JavaScript. No build step, no dependencies.

## Publish on GitHub Pages

1. Go to the repository's **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Pick the branch (e.g. `main`) and the **/ (root)** folder, then **Save**.
4. After a minute the site is live at `https://<username>.github.io/<repo>/`.

## Run locally

Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.
